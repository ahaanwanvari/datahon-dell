# Model training assessment

Reviewed commit: d6724a272778631c2b114badbd2b83f0ee854e46, Texas Flood Atlas.

The model call is `app.analyze`: two images plus dates/sensors/alignment produce JSON containing summary, kind, apparent strength, uncertainty and regional evidence. The application, not the model, builds timelines. Routes are generated by OSRM and screened by deterministic FEMA/TxDOT matching. Gauges, alerts and mapped hazards come from source feeds. The recovery calculator is arithmetic on user assumptions. There is no model training loop or trained-adapter serving configuration in the repo.

The existing local Qwen3-VL-8B-Instruct adapter was self-distilled from UTSA imagery: 457 train pairs, 85 validation pairs, one epoch. Its 542 targets include 480 water increases, 49 decreases, 9 stable and 4 uncertain observations. Its improved token loss measures agreement with Qwen-generated text, not independently verified flood detection. It contains no supervised single-image VQA, although the user now prompts new single images.

## Selected next training

- Continue the existing LoRA on published FloodNet Track 2 ground-truth questions about scene/road condition and yes/no flooding. Balance answer categories and cap repeated questions per image. Preserve original questions, answers, annotation paths, image hashes and pinned dataset revision.
- Exclude fine-grained building counts: 4000x3000 source imagery is reduced to 448 px, making exact object counts a poor training target at this budget.
- Replay UTSA paired-change examples to preserve the app JSON/timeline task, keeping their AI origin explicit.
- Add identical-image controls whose stable target follows from input equality. These do not imply the depicted scene is free of flooding.
- Freeze base weights and update the existing attention LoRA using a lower learning rate (2e-5), one epoch, assistant-only token loss.

The FloodNet mirror's official validation/test annotations omit answers. We regroup only the labeled original training pool by numeric filename hundred-blocks, excluding 5 images at each block boundary, before balancing or selection. No image or group crosses splits. This reduces adjacent-frame leakage but does not establish geographic independence: it remains one disaster/event. Evaluation is explicitly a local grouped holdout, not the official hidden benchmark.

Validation compares the prior adapter with the new checkpoint and checks paired-change loss for regression. Published-label VQA exact match, per-answer precision/recall and macro-F1 are evaluated on untouched held-out groups after training. Original base weights and the first adapter are preserved.

## Out of scope for this VLM training

Do not turn historical image descriptions into flood forecasts, flood depth, live street passability, evacuation orders or monetary loss estimates. The repository has no event-aligned training targets for these functions, and its current code does not delegate them to Qwen. Those functions would require different data, methods and validation.
